# 取舍与回归来源

对应 [#59 产品设计](../../../../docs/design/59-cite-decision-record/product.md) v1 的 S1.A1、S1.A2。按主手册 scratch install/doctor，读取安装后的 `keel-how`。必须用真实回答做独立判断，不能只摘录规则原文。

## Drive

没有图形入口。使用合成子系统，给出引入该行为的提交说明，以及可选的当时 PR/MR 讨论。提示中不给预期答案。

1. S1.A1：要求说明当前形状的取舍，或主张某次变更引入了问题。观察作者原文、推断标记和记录缺口。再给一份没有评审讨论的输入，观察不编造讨论。
2. S1.A2：要求只说明当前机制，观察不因未读历史而停下。另给一则尚无调查记录的缺陷，观察仍先从原入口复现并调查。

## Evidence / Cleanup

保存输入、宿主/模型、候选 SHA、时间、原始回答和逐项结果到 `.agents/verify-runs/59/<candidate>/`。两项都 pass 才汇总 S1。一次宿主上的通过不代表其它模型长期遵守。结束时 scratch uninstall，保留证据。
